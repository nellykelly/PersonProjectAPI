Privacy

What is collected, and nothing else:

  • Accounts (optional, only for the LeetCode tracker): a username and a hashed password. No email address is stored, and there is no email or marketing list.
  • Functional cookies: a signed session cookie, a random session_id used only to scope rate limiting, and a "remember me" cookie if you tick it at login. Nothing else.
  • Request logs for the assistant: for each chat message, a truncated copy of the question, the reply, timing, and your IP address stored only as a salted SHA-256 hash — never the raw IP. Used for the public usage stats page, which shows aggregates only.
  • Public submissions: character names and icebreaker answers in Pipeline World, and leaderboard names in Timed-Squares, are shown publicly by design.

No third-party analytics, advertising, pixels, or trackers run on this site — no Google Analytics, no Meta Pixel, nothing. Data is not sold or shared. Everything lives on a single European VPS. To request deletion of an account or a submission, email the address below.

Cookies

Only strictly necessary cookies are set (session, rate-limit scope, optional "remember me"). There are no advertising or analytics cookies, so there is no consent banner — there is nothing non-essential to consent to.

Accessibility

This site aims to meet WCAG 2.1 AA: semantic HTML and a single <h1> per page, a skip-to-content link, alt text on meaningful images (decorative images are marked empty), keyboard operability, visible focus outlines, a declared page language, and respect for prefers-reduced-motion. If something is hard to use with a screen reader or keyboard, please email the address below and it will be fixed.
